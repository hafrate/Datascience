# Datascience

🌟 **Vision**

Ce repository rassemble mes projets de Data Science, acquis depuis 2015, avec des objectifs clairs :
    
    * Appliquer des méthodes analytiques et de machine learning sur des problèmes financiers et opérationnels réels ou simulés
    * Conserver et structurer mes apprentissages, frameworks et pipelines pour un usage futur
    * Transformer le complexe en accessible, avec documentation, bottlenecks et analyses détaillées

🎯 **Objectifs principaux**

Préserver les projets réalisés avec R (tidyverse, tidymodels, sparkyR), Python (pandas, scikit-learn, seaborn) et Spark

    * Montrer l’application concrète de techniques avancées :
    * Modélisation prédictive (churn, défaut de paiement)
    * Analyse de la valeur client et revenue forecasting
    * Simulation et optimisation financière
    * Visualisation et dashboards interactifs (Shiny / Power BI)
    * Documenter les choix méthodologiques, les obstacles et solutions, pour que chaque projet soit réutilisable et compréhensible


🔧 **Outils et technologies utilisés**

    * R : tidyverse, tidymodels, sparkyR, Shiny
    * Python : pandas, scikit-learn, seaborn, matplotlib
    * Big Data / Spark : SparklyR, PySpark pour pipelines distribués
    * Power BI / Excel : visualisation et prototypage rapide
    * Git / GitHub : versionning et organisation des projets
